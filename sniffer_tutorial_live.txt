#### Passo 1: Prepara il "Campo di Battaglia" (Rete e Vittima)

Apri un terminale e crea la rete isolata e il computer vittima:

```bash
# 1. Crea la rete dedicata (come da guida)
docker network create --subnet=172.20.0.0/16 nids_test_net

# 2. Crea la VITTIMA (un server web Nginx leggero) all'IP 172.20.0.2
# Questo è il pezzo che mancava!
docker run -d --name vittima --net nids_test_net --ip 172.20.0.2 nginx

```

#### Passo 2: Trova l'Interfaccia Giusta

Quando crei una rete Docker, il tuo PC crea una nuova scheda di rete virtuale (di solito inizia con `br-`). Dobbiamo dire allo sniffer di ascoltare su quella, non su `docker0` generico.

Esegui:

```bash
ifconfig

```

Cerca un'interfaccia che ha un IP tipo `172.20.0.1`. Probabilmente si chiamerà `br-<qualche_numero>`.
*Esempio: `br-0a1b2c3d4e5f*`. Copia questo nome.

#### Passo 3: Terminale 1 - Avvia lo Sniffer

Usa il nome dell'interfaccia trovato sopra (sostituisci `br-TUO_ID`):

```bash
# Sostituisci 'br-TUO_ID' con il nome trovato con ifconfig
sudo ./venv/bin/python -m src.sniffer.main live \
    --interface br-TUO_ID \
    -v \
    -o reports/docker_attack_test.json

```

#### Passo 4: Terminale 2 - Lancia l'Attacco

Ora attacchiamo la vittima (`172.20.0.2`) dal tuo PC.

**Simulazione Port Scan (Nmap):**

```bash
# Scansiona la vittima sulla porta 80 (che sappiamo essere aperta su Nginx)
sudo nmap -sS -p 80 172.20.0.2

```

**Simulazione DoS (Hping3 - Opzionale):**

```bash
# Invia un flood SYN alla vittima
sudo hping3 -S --flood -p 80 172.20.0.2

```

SE SI BLOCCA:
Quando vedi che premi Ctrl+C e lui scrive "Interruzione richiesta" ma rimane bloccato:

    Lascialo bloccato nel Terminale 1.

    Vai nel Terminale 2 (o aprine un altro).

    Manda un singolo pacchetto verso l'interfaccia monitorata (nel tuo caso 172.20.0.2 o anche broadcast):
    Bash

    ping -c 1 172.20.0.2

    Spiegazione: L'arrivo di questo nuovo pacchetto "sveglia" lo sniffer che era in attesa, gli fa processare il ciclo, si accorge che hai premuto Stop e finalmente si chiude salvando il JSON.
